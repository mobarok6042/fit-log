#  FitLog

**FitLog** is a modern fitness and workout library built with Next.js. It provides users with a simple and organized way to explore different workouts, view detailed workout information, and follow step-by-step exercise instructions.

##  Technologies Used

* **Next.js** – React framework for building the application
* **React** – For building reusable UI components
* **JavaScript** – For application logic and functionality
* **Tailwind CSS** – For responsive and modern styling
* **DaisyUI** – For reusable UI components
* **React Icons** – For icons throughout the application
* **REST API** – For fetching workout data

##  Key Features

1. **Workout Library**
   Browse a collection of workouts covering different muscle groups and exercise types.

2. **Detailed Workout Information**
   Each workout provides useful information such as difficulty, sets, reps, duration, calories burned, and rating.

3. **Step-by-Step Instructions**
   Users can view numbered instructions to understand how each exercise should be performed.

4. **Responsive Design**
   The website is designed to provide a smooth experience across mobile, tablet, and desktop devices.

5. **Reusable Components**
   The application is built with reusable React components such as workout cards, navigation, banners, and workout sections for a clean and maintainable codebase.
